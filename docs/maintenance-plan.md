# ProxyAll 后续改动的触发条件

1. **新增节点协议**：先确定归入哪个 `lib/sb_proto_*.sh`（TCP/Reality、AnyTLS、TLS/CDN、QUIC、基础代理、XHTTP）。从 `_show_add_node_menu` 和 `lib/sb_nodes.sh` 列出该协议在创建、查看、编辑、改端口、删除及聚合订阅中的调用点，用一个完整的节点生命周期样例固定预期，再补齐各分支。事务提交和失败回滚交给 `lib/sb_tx.sh`。验收覆盖旧节点缺失新增字段及客户端真实导入。
2. **按协议集中分派**：`lib/sb_nodes.sh` 的查看、删除、改端口仍按类型分支。若同一协议的分支继续分散，可为每个协议组提供 `link`、`clash`、`port`、`delete` 函数并按类型登记，先用现有测试固定各协议输出再迁移。
3. **统一证书签发**：`sb`（`lib/sb_origin.sh`，`--nocron` 由自身续期）与 `nginxproxy`（`deploy.sh`，acme.sh 自带 cron 与下载镜像）已共用 acme.sh 版本与哈希，安装与续期流程仍各自实现。合并前先写契约测试覆盖两种续期方式、证书目录与重载钩子，再提取公共实现。
4. **扩展共享 443**：将两端依赖的锁顺序、SNI 所有者及服务重载失败恢复写成契约测试，在独立入口与统一菜单都运行同一组用例，并通过真实 HAProxy 共享入口。
